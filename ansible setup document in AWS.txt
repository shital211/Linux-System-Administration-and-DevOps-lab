    ****How to Setup Ansible Lab on AWS & Linux With non root sudo user****

Steps:- 
1)requirement for setting up ansible infra

Linux and EC2 server name:- Ansible_controller
4GB RAM
2 Core processor

2) Linux or EC2 (n) number of nodes as worker or hosts & ansible nodes
	
3) Launch 3 EC2 instance in mumbai region with SG having ssh,icmp,http open & name {all in Same AZ}
    Ansible_controller
	Ansible_node1
	Ansible_node2

4) Networking and Hostname to be configured accordingely so that they ping
    other
	#sudo su -
   #hostnamectl set-hostname ansiblecontroller.radical.com
   #hostname
   #bash
   #ifconfig ----->172.31.40.41 this is private ip
go to node 1 & node2 and perform the same steps likes above
For Node1
    #sudo su -
   #hostnamectl set-hostname node1.radical.com
   #hostname
   #bash
   #ifconfig----->172.31.46.241 this is private ip of node1
For Node2
   #sudo su -
   #hostnamectl set-hostname node2.radical.com
   #hostname
   #bash
   #ifconfig----->172.31.46.176 this is private ip of node2
   
From controller node ping ip of node1 & node2 should be successfull

5) Install ansible package only on ansiblecontroller rest all agentless
    #yum search ansibl*
	#yum info ansible-core.x86_64
	#yum install -y  ansible-core.x86_64
	#ansible --version
	#python3 --version
	
6) Below commands are suppose to be executed on all machine controller+nodes
     #useradd ansadmin
	 #passwd ansadmin
Now, Making ansadmin as sudo user on all nodes {sudo means run as admin/root}
     #nano -l /etc/sudoers
Now to go 100 line number then add below entry	 
	 ## Allow root to run any commands anywhere
root    ALL=(ALL)       ALL
ansadmin ALL=(ALL)      NOPASSWD: ALL
now to save this file used {ctrl+x} then press Y then enter.

Now, ssh configuration on all nodes for allowing different ways of authentication
    #nano -l /etc/ssh/sshd_config
change this line to below values
#PermitRootLogin prohibit-password----->line number 40
PermitRootLogin yes ------------------->above line should look likes after change

#PubkeyAuthentication yes------>line number 46
PubkeyAuthentication yes  ------------------->above line should look likes after change

#PasswordAuthentication no------>comment this line number 67
PasswordAuthentication yes ------------------->above line should look likes after change

Now, we need to restart sshd service on all nodes
  #systemctl restart sshd
  
Step 7:- ******All the below steps now to be done only on controller node*****

Login as ansadmin user 
first Login ec2-user then 
     #sudo su - 
     #su - ansadmin
	 $ssh-keygen -t rsa ------>{generate public & private key as ansadmin}
	 $ssh-copy-id ansadmin@172.31.46.241   --->{private ip of node1}
	 $ssh ansadmin@172.31.46.241 ----->{this must work without password or else 
	                                      troubleshoot}
										  
	 $ssh-copy-id ansadmin@172.31.46.176   --->{private ip of node2}
	 $ssh ansadmin@172.31.46.176 ----->{this must work without password or else 
	                                      troubleshoot}
